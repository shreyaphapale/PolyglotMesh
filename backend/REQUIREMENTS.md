# PolyglotMesh - Project Requirements

## Functional Requirements

1. The system should accept source code from users.
2. The system should support multiple programming languages.
3. The backend should process execution requests.
4. The system should display program output.
5. The system should handle execution errors.

## Technical Requirements

- Java
- Spring Boot 3
- GraalVM Polyglot
- Spring WebFlux
- React
- Monaco Editor
- Maven

## Security Requirements

- Restrict unauthorized system access.
- Isolate code execution contexts.
- Handle execution time limits.
- Prevent unsafe code execution.

## Future Scope

- Add Python and JavaScript execution.
- Implement execution monitoring.
- Add performance metrics.
