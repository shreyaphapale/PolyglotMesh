
# PolyglotMesh Backend

## Project Description
PolyglotMesh is a multi-language runtime sandbox
designed to execute different programming languages
within a single Java Virtual Machine.

## Backend Technologies
- Java 21
- Spring Boot 3
- Spring WebFlux
- GraalVM Polyglot Engine
- Maven

## Main Features
1. Receive code execution requests.
2. Execute Python and JavaScript code.
3. Return execution results.
4. Handle runtime errors.
5. Apply secure execution restrictions.
